# CSC4110 Group 01 Project

## Student Performance Analysis and Prediction

### Project Overview
This project focuses on analysing student performance factors and developing machine learning models to predict examination scores and identify students likely to achieve a score of 70 or above.

The project aims to generate insights that can support Elimu Bora Trust in selecting students for mentorship scholarships and identifying effective study habits across its 40 schools in Bungoma County.

### Project Objectives
- Explore student performance data.
- Identify factors associated with examination performance.
- Develop regression models to predict examination scores.
- Develop classification models to identify students likely to score 70 or above.
- Evaluate model performance and provide useful insights.

### Dataset
The project uses publicly available student performance data containing factors such as attendance, hours studied, previous scores, tutoring sessions, physical activity, sleep hours and parental involvement.
